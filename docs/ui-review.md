# UI刷新(v4)の自己採点

2026-10。基準は「ポップで洗練されている」「AIが作った安っぽさがない」。
採点は、Chromium(疑似カメラ・iPhone相当の画面サイズ)で撮影した画面で行った。実機のiPhoneでは未確認。

## 設計の要点
- 推しカラー(`--theme`)が、選択・許可・読み込み・撮影結果の地色になる。色は推しの色+黒+白だけ。
- 撮影中はカメラ映像が主役。操作は、メニュー1つ・ポーズ/表情のチップ・シャッターだけ。
- 文字は2種類。見出し・名前・数字=Dela Gothic One(使う文字だけのサブセットを同梱)、それ以外=iPhone標準のヒラギノ角ゴ。
- 角丸は役割で変える(操作=丸、面=28px、写真プリント=4px)。絵文字は使わない。

## 採点(10点満点×8項目)
| 項目 | 点 | 根拠と、足りないところ |
|---|---|---|
| コンセプトの一貫性 | 8.5 | 画面の始まりと終わりが推しカラーで揃う。足りない: 選択画面の上半分は、まだ3Dの推しがいない(レンズの線画で埋めている) |
| 階層とタイポグラフィ | 8.5 | 名前→状態→ボタンの順が一目で分かる。足りない: 本文のヒラギノは、実機で未確認(撮影環境に無い) |
| 色とポップさ | 8 | 平塗りの高彩度+黒。推し3人で彩度の釣り合いが取れている |
| 仕上げの精度 | 7.5 | 撮影して見つけた不具合(重なり順、フォント、無効なfont指定、名前の位置ずれ、SE画面でのレンズの衝突)を直した。足りない: 影の調整、指差し、カウントダウン、動画モードは撮影・確認していない |
| 操作のわかりやすさ | 7 | 選ぶ→(取り込み)→許可→立ち位置→撮影。足りない: 初回は4手順。ポーズ選択は「矢印で送る」から「直接タップ」に変えたが、実際に使っての確認はまだ |
| 安っぽさの回避 | 7.5 | グラデの洗い・絵文字アイコン・英字の大文字ラベル・カードの入れ子は無い。足りない: 「太字の和文+黒い丸ボタン+平塗り」は流行の型でもあり、レンズの線画も装飾の域を出ない |
| アクセシビリティ | 7 | 黒文字は推しカラー上で7.8〜13.6:1。ガラス調チップの白文字は、白壁の前でも5.3:1(直す前は3.4:1だった)。タップ領域は44px以上、動きの低減に対応。足りない: タブのARIA(tablist)が未完、実際のVoiceOverは未確認 |
| 実機での確からしさ | 6 | 3つの画面サイズで選択画面を確認。足りない: iOS Safariのセーフエリアやbackdrop-filterやscroll-snap、フォント表示、カメラの実映像は未確認 |

合計 60/80(100点換算で約75点)。
